技術原理

XRF 光譜技術 + 紫砂專業 Know-how

四層架構，從原始數據到標準化報告

LAYER 01
XRF Data Parser
解析原始數據、元素濃度、譜圖與 metadata
LAYER 02
Analysis Engine
元素整理、比值計算、異常檢查與規則運算
LAYER 03
Reference Engine
比對參考樣本與合作方數據，輸出相似性結果
LAYER 04
Report Engine
產生圖表、分析文字、模板版面、編號與 PDF

合作方設備

EDX 8500 EDXRF Spectrometer
JPSPEC 佳譜儀器（蘇州）
  • • 探測器：高性能矽漂移探測器（SDD）
  • • 元素範圍：Mg（12）～U（92）
  • • 能量分辨率：約 140±5 eV
  • • 台式機型，適合精確溯源比對

五項核心指標

  • ① 指紋譜（元素指紋圖譜）
  • ② 矽鋁比（SiO₂/Al₂O₃）：0.32–0.38
  • ③ 鉀鈣比（K₂O/CaO）
  • ④ 銣鍶比（Rb/Sr）：礦層越深越低
  • ⑤ 鉀鈉鈣鎂協同比
